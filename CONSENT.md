# Einwilligung / Consent (anonym)

**Zweck:** Dieses Experiment speichert **anonymisierte** Session-Ergebnisse zur Auswertung (PSI/Intuition/Einflussnahme). Es werden **keine personenbezogenen Daten (PII)** erhoben und **keine Tracking-Cookies** gesetzt.

## Was wird gespeichert?
- Messwerte pro Session (z. B. Dauer, Schritte, Treffer, Z-/p-Werte, Startfeld, Geschwindigkeit).
- Eine **zufällige, anonyme Kennung (UID)** im Browser (localStorage), damit mehrere Sessions derselben Person statistisch zuordenbar sind – ohne Identitätsbezug.
- Zeitpunkt der Messung (`ts`).

## Wo werden Daten gespeichert?
- In einem projektspezifischen Speicher (**Vercel Blob**). Jede Session als einzelne Datei (one-record-per-file).

## Rechtsgrundlage & Dauer
- Forschungs-/Evaluationszwecke. Aufbewahrung projektspezifisch (Empfehlung **90 Tage**).

## Deine Rechte
- Auskunft/Löschung auf Anfrage. Kontakt gemäss **public/privacy.html** (Impressums-Link optional).
- Export deiner Daten möglich (CSV/JSONL) via Projekt-Exportseite oder Anfrage.

**Mit Starten/Beenden einer Session erklärst du dich mit dieser anonymen Speicherung einverstanden.**
(Stand: 2025-10-30)
